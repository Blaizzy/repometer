iHow this comparison works+

Both repositories use physical line counts, including comments, blank lines, and a final line without a newline. Documentation, generated files, and vendored text are included. Folders include all their subfolders.

Common binary file types, non-UTF-8 files, symlinks, and submodules are excluded. Filters apply equally to both sides. File types are grouped by extension.

Each repository is counted at its displayed commit. The comparison updates only after both counts finish. It checks for changes every two minutes while connected to GitHub, or five minutes without authentication, while visible; previous complete counts stay visible if an update fails. Editing a repository, branch, or folder pauses refresh until you compare again.

This compares codebase sizes; it does not compare matching files, code quality, or Git history. Public repositories only.
