iHow these lines are counted+

Counts come from GitHub file contents at the displayed commit. A physical line includes comments, blank lines, and a final line without a trailing newline. Documentation, generated files, and vendored text are included; this is not an executable-statement count.

Common binary-asset extensions, non-UTF-8 files, symlinks, and submodules are excluded and reported above. A folder includes all its subfolders. File-type and path filters apply to the displayed totals.

PR counts compare the merge base with the PR head, using file paths. Renamed or consolidated files can appear as removed and added paths. GitHub’s diff totals cover the entire PR; line counts do not measure test quality or coverage.
